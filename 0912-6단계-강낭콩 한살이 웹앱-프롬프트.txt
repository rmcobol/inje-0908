<<강낭콩 한살이 웹앱 만들기>>

1. 디자인 적용하여 프롬프트 입력하기

너는 아이들의 상상을 그려 내는 작가야. 아이가 식물의 상태를 말하면, 그에 맞는 이미지를 즉시 그려 줘. 아래의 스타일로 표현해야 해.

전체 디자인 설정:
## 톤: 생명력, 치유, 유기적, 느림, 자연주의, 보타니컬 가든
## 색상:
- 배경색: #F0F4EC(연한 세이지 그린, 아침 안개가 낀 새벽 정원처럼 싱그러운 색)
- 텍스트 색상: #2C4A1E(딥 포레스트 그린, 깊은 숲속 나뭇잎처럼 진하고 신뢰감 있는 색)
- 강조 색상: #E8C4A0(따뜻한 베이지, 햇살을 머금은 흙이나 마른 씨앗 같은 색), #C9E0C0(소프트 민트, 갓 피어난 새싹처럼 여리고 투명한 색)
## 이미지 스타일:
- 특징: 수채화로 그린 식물 세밀화 느낌. 붓 터치가 느껴지고, 색이 자연스럽게 번지는 유기적인 질감
- 이미지: 화면 하단에는 따뜻한 베이지색(#E8C4A0) 흙과 연한 세이지 그린(#F0F4EC) 풀밭이 수채화 물감으로 부드럽게 펼쳐져 있어.
- 텍스처: 거친 종이 결이 느껴지는 수채화 종이 질감. 물감의 얼룩과 번짐이 자연스럽게 살아 있어 손으로 직접 그린 듯한 따뜻함을 줘.
## 구성: 비대칭 배치. 중앙의 식물은 약간 오른쪽으로 치우쳐 있으며, 왼쪽 여백에는 잎맥이 보이는 나뭇잎, 작은 들꽃, 씨앗 단면도가 수채 번짐 효과와 함께 자유롭게 산재되어 유기적인 흐름을 만들어.
## 타이포그래피:
- 제목: 우아한 이탤릭 세리프. 섬세하고 가는 획으로 식물 학명을 라틴어 스타일로 적은 듯한 필기체 느낌
- 스타일: 섬세한 획과 자연스러운 기울기, 수채화 세밀화의 감성과 어우러지는 우아하고 따뜻한 느낌

2. 학습 과정에 맞게 프롬프트 입력하기

2-1. 강낭콩 심기

강낭콩을 심어 볼 거야. 화면 아래쪽에 흙을 깔고, 그 안에 작은 강낭콩 씨앗을 그려 줘.

2-2. 제목 바꾸기

제목을 강낭콩의 한살이로 바꿔 줘.

2-3. 씨앗 틔우기

이제 씨앗에서 연두색 작은 싹이 고개를 쏙 내밀게 해 줘.

2-4. 줄기와 잎사귀 성장시키기

줄기가 화면 중간까지 쑥쑥 자라게 해 줘. 잎사귀도 더 커졌으면 좋겠어.

2-5. 꽃과 나비 추가하기

줄기 끝에 예쁜 꽃을 피워 주고, 꽃 옆에는 탐스럽게 익어 가는 강낭콩 꼬투리가 여러 개 달리게 해 줘. 꽃 주변에는 나비가 날아다니게 해 줘.

3. 인터랙티브 웹앱으로 확장하기

3-1. 웹앱 만들기

너는 아이들이 식물의 일대기를 단계별로 체험할 수 있도록 반응형 웹앱을 만들어 주는 개발자야.

[디자인 가이드라인 - 필수 준수]
## 톤: 생명력, 치유, 자연주의. 수채화 세밀화 특유의 부드럽고 따뜻한 감성
## 색상
- 배경색: #F0F4EC(연한 세이지 그린)
- 텍스트 색상: #2C4A1E(딥 포레스트 그린)
- 강조 색상: #E8C4A0(따뜻한 베이지), #C9E0C0(소프트 민트)
## 이미지 스타일
- 텍스처: 거친 종이 질감과 수채화 물감이 번지는 효과를 CSS와 SVG 필터로 구현할 것
## 타이포 그래피
- 글꼴: 제목과 상태 메시지는 ‘우아한 세리프체(명조 계열)’를 사용하고, 강조하고 싶은 부분은 이탤릭체로 표현할 것. 모든 텍스트는 한국어로 출력해 줘.

[단계별 체험 로직 및 한국어 메시지]
1단계: 씨앗 심기
화면 옆에 놓인 ‘강낭콩 씨앗’을 마우스로 드래그해서 중앙의 ‘포근한 흙’ 위로 옮기면 흙 속으로 쏙 파묻히는 애니메이션을 보여 줘.
성공 시 상단 메시지: “씨앗이 포근한 흙 속에서 잠들었어요.”

2단계: 물 주기와 발아
‘물 주기’ 버튼이 나타남. 클릭할 때마다 물방울이 수채화처럼 번지며 떨어지는 효과
3번 클릭 시 씨앗에서 연두색 싹이 쏙 올라옴.
성공 시 상단 메시지: “와! 소중한 첫 싹이 기지개를 켜며 깨어났어요.”

3단계: 햇살과 줄기 성장
화면 상단에 ‘황금빛 해님’ 아이콘 등장. 해님을 마우스로 움직이면 줄기가 해님 방향을 따라 부드럽게 기울어지며 쑥쑥 자라남.
줄기 내부에는 ‘소프트 민트색’ 물길이 반짝이며 흐르는 효과를 줄 것
성공 시 상단 메시지: “햇살을 듬뿍 받은 줄기가 하늘을 향해 쑥쑥 자라요.”

4단계: 개화와 일기 쓰기
충분히 자라면 강낭콩 꼬투리가 여러 개 달리고 꽃 주위에 나비들이 날아다님.
하단에 ‘오늘의 정원 일기’ 입력창 등장. 아이가 내용을 입력하면 화면 여백에 예쁜 필기체로 일기가 기록됨.
최종 메시지: “세상에서 가장 아름다운 꽃이 피었습니다!”

[기술 요구 사항]
모든 코드는 단일 HTML 파일 내에 작성(CSS, JS 포함)
이미지는 외부 링크 없이 SVG나 CSS 도형으로 수채화 느낌이 나도록 직접 구현할 것
사용자 경험(UX)이 매끄럽고 로딩 속도가 빠르도록 최적화할 것
